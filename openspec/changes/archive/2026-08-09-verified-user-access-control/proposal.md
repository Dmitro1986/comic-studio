# Proposal: Verified User Access Control (Web & Telegram Bot)

## Summary
Внедряет единую систему проверки подлинности и разграничения доступа для незарегистрированных / неавторизованных пользователей к Веб-сайту (`/ui/`, `/comics/`, `/api/*`) и Telegram-боту.

## Problem Statement
В настоящее время:
- Доступ к веб-интерфейсу `/ui/` и открытым роутам `/api/` не требует обязательного подтверждения личности пользователя при локальном/проксированном запуске.
- Telegram-бот проверяет только совпадение с единым `CHAT_ID`, что усложняет масштабирование доступа для нескольких верифицированных пользователей или коллег.

## Proposed Changes
1. **Telegram Bot Multi-User Authorization**:
   - Динамическая проверка разрешённых пользователей из списка `ALLOWED_TELEGRAM_USERS` в `.env` и локального реестра `data/allowed_users.json`.
   - Защита всех команд бота: незарегистрированные юзеры при обращении видят сообщение с их Telegram ID и предложением запросить доступ у администратора или ввести инвайт-код (`/verify <code>`).
   - Команды администрирования бота для динамического управления пользователями: `/add_user <id>`, `/remove_user <id>`, `/users`.

2. **Web Site & API Security (Гибридный режим)**:
   - **Telegram MiniApp (внутри Telegram)**: Бесшовная аутентификация по HMAC-SHA256 подписи `Telegram.WebApp.initData`. Если Telegram ID пользователя входит в список разрешённых, доступ к дашборду и API предоставляется автоматически.
   - **Обычный браузер / Прямой заход**: Защита входа через секретный токен доступа / PIN-код (`WEB_AUTH_PASSWORD` в `.env`) или ввод проверочного токена сессии в Cookie / Bearer header.
   - Автоматическая подстановка токенов и initData во все клиентские вызовы API (`apiFetch`).

## Success Criteria
- Незарегистрированные пользователи получают HTTP 401/403 в Web API и уведомление об ограничении доступа в Telegram-боте.
- Верифицированные пользователи из списка разрешённых получают мгновенный доступ к `/ui/` в Telegram MiniApp и веб-браузере.
- Все существующие unit-тесты Web API и Telegram-бота проходят без ошибок.
