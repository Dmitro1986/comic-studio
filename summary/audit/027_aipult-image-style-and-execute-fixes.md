# Аудит: Поддержка смены стиля рисунка в AiPULT и отладка кнопки выполнения (▶️ Run)

## 1. Контекст
Пользователь обратился с запросами:
1. Возможность менять не только стиль бабблов/текста (`bubble`, `gothic`, `star`), но и арт-стиль рисунка (`anime`, `realistic`, `cyberpunk` и т.д.) через интерактивный чат **🤖 AiPULT**.
2. Отсутствие кнопки `▶️ Run` на сформированной карточке `revise` в UI.
3. Возникающие ошибки при выполнении (`exit -1`, `HTTP 400`, `INVALID_CARD_ID`).

## 2. Что сделано
- **Распознавание стилей рисунка в AiPULT (`web/lib/aipult/heuristic.js`)**:
  - Добавлены паттерны `IMAGE_STYLE_PATTERNS` (`anime`, `realistic`, `cyberpunk`, `noir`, `cartoon`, `fantasy`, `comic`) и ключевые слова арта (`рисунок`, `арт`, `картинка`, `графика`).
  - Команды изменения стиля рисунка маршрутизируются в интент `revise` с генерацией команды `python3 scripts/revise_scenario.py --scenario-id <id> --feedback "Смени стиль рисунка на anime"`.
- **Включение исполняемой кнопки `▶️ Run` в UI (`ui/aipult.js`)**:
  - Расширен набор `EXECUTABLE` с `['restyle']` до `['restyle', 'render', 'revise']`.
  - Добавлено автоизвлечение `scenario_id` из текста команды (`--scenario-id <id>`), если параметр отсутствовал в объекте карточки.
- **Серверная валидация карточек и выполнение (`web/routes/aipult.js`)**:
  - Ослаблены требования к наличию `card_id` в POST `/api/aipult/execute`: при отсутствиигенерируется временный ID (`card_<timestamp>_<rand>`), предотвращая ошибку `HTTP 400 INVALID_CARD_ID` для карточек из `localStorage`.
  - Обеспечена валидация `scenario_id` только при наличии непустой строки.
  - Проброшено поле `feedback` в аргументы карточки `card`.
- **CLI ревизии и сценарист Python (`scripts/revise_scenario.py` и `py/scenario/writer.py`)**:
  - Параметр `--scenario-path` сделан опциональным с автопоиском файла сценария по ID в `data/scenarios/`.
  - Добавлена гибкая обработка текстовых отзывов в `--feedback` (строки автоматически преобразуются в список).
  - В `_format_feedback_history` добавлена поддержка элементов истории типа `str`.

## 3. Зафиксированное текущее состояние
- Функция добавлена и закоммичена в репозиторий.
- Все 115 тестов Node.js и 75 тестов Python успешно проходят.
- Пользователь отметил, что кнопка выполнения пока требует дополнительной отладки со стороны браузера/клиента. Работа будет продолжена.
