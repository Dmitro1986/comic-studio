# Аудит: Вывод и поддержка редактирования (Revision & Restyle) на карточках черновиков (Draft)

## 1. Контекст
В Web UI на карточках со статусом `draft` отображались только 3 действия (`✅ Утвердить`, `❌ Отклонить`, `🗑 Удалить`). Пользователь не имел возможности подправить текстовый сценарий, реплики панелей или стиль баблов до отправки на дорогостоящий рендер нейросетью. Кроме того, бэкенд `POST /api/scenarios/:id/restyle` блокировал вызов для не-отрендеренных сценариев с кодом `409 INVALID_STATE`.

## 2. Что сделано
- **Web API (`web/routes/scenarios.js`)**:
  - Разрешен вызов `POST /api/scenarios/:id/restyle` для сценариев в статусах `draft` и `approved`.
  - Для сценариев без отрендеренных картинок обновляются `style` и `panels[].caption` в `JSON`-файле сценария, а выполнение Python-скрипта `restyle.py` автоматически пропускается.
- **Web UI (`ui/app.js`)**:
  - Добавлены кнопки `🔄 Revision` (перегенерация через LLM с фидбеком) и `⚡️ Быстрая правка` (редактирование текста панелей и визуального стиля баблов) в секцию действий карточек со статусом `draft` и `approved`.
- **Тесты (`web/tests/operations.test.js`)**:
  - Добавлен автоматический юнит-тест проверки работы `restyle` для `draft` сценариев.

## 3. Статус
