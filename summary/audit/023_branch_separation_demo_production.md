# Аудит: Разделение веток main (полная) и demo-production (демо)

## 1. Контекст
В ходе работы текущий рабочий каталог сервера находился на ветке `main`, куда ошибочно попадали изменения демо-производства (отключение тяжелых ML-библиотек). Требовалось чётко разделить ответственность веток:
- `main`: содержит полную версию проекта со всеми зависимостями (`yt-dlp`, `openai-whisper` и полной интеграцией).
- `demo-production`: содержит адаптированную версию для слабых серверов (1GB RAM) с заглушками тяжелых ML-модулей.

## 2. Что сделано
- **Ветка `main`**:
  - Выполнен откат коммита с заглушками (`c462eb1`).
  - Восстановлены файлы `py/ingest/youtube.py` и `py/requirements.txt` с полными зависимостями (`yt-dlp`, `openai-whisper`).
  - Все последние исправления (MCP порт 3000, CSS шаблоны, тесты) сохранены в `main`.
  - Ветка зафиксирована и закоммичена в `origin/main`.
- **Ветка `demo-production`**:
  - Локальная рабочая копия на демо-сервере переключена на ветку `demo-production`.
