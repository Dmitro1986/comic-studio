# Аудит: Исправление порта MCP-сервера и сохранение CSS дочерних комбинаторов

## 1. Контекст
В процессе проверки инфраструктурных портов и рендеринга шаблонов комиксов были выявлены и исправлены две проблемы:
1. `mcp-server/index.js` обращался по умолчанию к порту 3300 вместо стандартного веб-порта проекта 3000 (`API_BASE_URL`).
2. В шаблоне Jinja2 `comic.html.j2` механизм `autoescape` экранировал символы `>` в `&gt;` при вставке CSS-стилей, что ломало дочерние селекторы видов `main.comic--comic > .panel:nth-child(N)`.

## 2. Что сделано
- **`mcp-server/index.js`**:
  - Порт по умолчанию для `API_BASE_URL` изменён с `3300` на `3000`.
- **`py/render/html_renderer/templates/comic.html.j2`**:
  - Вставка `{{ css }}` заменена на `{{ css | safe }}` с поясняющим комментарием о необходимости предотвращения экранирования селекторов комбинаторов дочерних элементов `>`.
- **`tests/test_html_renderer.py`**:
  - Добавлен тест `test_child_combinators_preserved_in_css`, проверяющий сохранение исходных селекторов с `>` и отсутствие `&gt;` в сгенерированном HTML.

## 3. Статус
✅ **Завершено**. Все тесты Node.js (110/110) и Python (60/60) успешно проходят.
