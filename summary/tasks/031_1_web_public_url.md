# Задачи: WEB_PUBLIC_URL — ссылки на HTML в Telegram

## Статус: Pending

## Описание
Настроить WEB_PUBLIC_URL для добавления ссылок на HTML-версию комикса в Telegram-caption.

## Задачи

| ID | Задача | Приоритет |
|---|---|---|
| 1 | Добавить WEB_PUBLIC_URL в .env (на сервере Dmitro) | high |
| 2 | Проверить что Telegram-бот добавляет ссылку в caption | high |
| 3 | Проверить inline-кнопку "Открыть HTML" | medium |

## Примечание
Требует внешний IP или домен для сервера.
