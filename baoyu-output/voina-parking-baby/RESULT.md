# Результат: «Пять дней» — 5 комиксов в стиле S.T.A.L.K.E.R.

## Проект
Военный документальный комикс. История: новорождённая девочка (5 дней от роду) проводит ночь в киевском паркинге под обстрелом. Рассказ от лица одесской подруги.

**Визуальный стиль:** S.T.A.L.K.E.R. — грязные охряные/ржавые тона, поцарапанный металл, бетон с трещинами, контрастный свет сквозь щели. Без графического насилия (только последствия: вибрация, тень, гул).

**Подписи:** На украинском/русском, стиль `memo` (нейтральный, как рукописная заметка).

## Процесс

1. **Создание сценариев:** 5 комиксов через `create_comic` (image_style=realistic, caption_style=memo)
2. **Утверждение:** все 5 → `approved`
3. **Рендер:** 2 прошли через job runner, 3 провалились с `PROCESS_FAILED` (таймаут Python процесса)
4. **Восстановление:** 3 fallback через ручной `python3 scripts/render_approved.py --scenario-id <id>`
5. **Итог:** все 5 в статусе `rendered`, PNG файлы доступны

## Технические проблемы

- Web job runner (`web/lib/process_runner.js`) имеет недостаточный таймаут для MiniMax API (каждый панель ~30-60 сек, итого 3-5 мин на комикс)
- При превышении таймаута job падает с `PROCESS_FAILED`, exit_code=1, но сценарий остаётся в `approved`
- Решение: ручной запуск через `python3 scripts/render_approved.py` обходит таймаут web runner

## Использование

Все PNG в `comics/` можно:
- Открыть локально
- Поделиться через Telegram/Notion/соцсети
- Загрузить в `/comics/<id>.png` эндпоинт web API: `http://127.0.0.1:3000/comics/db0e28a4.png`
